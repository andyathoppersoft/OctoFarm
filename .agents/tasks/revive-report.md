# OctoFarm revive: verification note

## Result
Install and client build work on Node 24.16 / npm 12.2. The app starts and runs until it connects to MongoDB, which is not installed on this machine. Serving HTTP could not be verified because of that.

## What was broken
1. `npm ci` in `server/` failed on npm 12: the lockfile lacked the optional `fsevents@2.3.3` entry. This broke `npm run install-server`, `setup-dev` and `npm start` (its `prestart` runs `npm ci`).
2. MongoDB is not available (no mongod, docker or service; nothing on 127.0.0.1:27017). The app logs `MongooseServerSelectionError: connect ECONNREFUSED 127.0.0.1:27017` and does not serve.
3. `.env` held only `SUPER_SECRET_KEY`, so `MONGO` and the port were unset.

## Files changed
- `server/package-lock.json` (tracked): regenerated by `npm install` in an earlier step; adds the `fsevents` entries (+22 lines). No dependency versions changed.
- `.env` (gitignored, repo root): added `NODE_ENV=development`, `MONGO=mongodb://127.0.0.1:27017/octofarm`, `OCTOFARM_PORT=4000`, as the README specifies.
- No source, no dependency bumps, no commits.

## Commands run and results
- `cd server; npm ci`: succeeds now (warns that install scripts for bufferutil, sharp, storage-engine and utf-8-validate are blocked; 74 audit findings reported).
- `cd client; npm run build` (earlier step): webpack 5.74 compiled with 3 size/performance warnings only. No OpenSSL flag needed.
- `cd server; node app.js` (OCTOFARM_PORT=4000 via `.env`): env and logger setup pass, then ECONNREFUSED to MongoDB. The process was stopped afterwards. HTTP request to http://localhost:4000 not possible because the server never listens before the DB connects.

## Start command and URL
```
cd d:\Projects\OctoFarm\OctoFarm\server
node app.js            # or: npm run dev (nodemon)
```
URL: http://localhost:4000 (change `OCTOFARM_PORT` in `.env`). `npm start` also needs pm2 installed globally.

## Left for you to decide
- MongoDB (required). Choose one: install MongoDB Community Server as a Windows service (mongoose 6 supports server 3.6 to 7.x); install Docker Desktop and run `docker run -d -p 27017:27017 mongo:7`; or set `MONGO` in `.env` to a MongoDB Atlas connection string. Then start the app and open http://localhost:4000.
- `sharp@0.30.7` has no native binary because npm 12 blocks its install script. It is not used in server source, so startup is unaffected. Options: leave it, remove the dependency, or `npm install-scripts approve sharp`.
- `npm audit`: server 74 (8 critical), client 30. Clearing these needs major upgrades (mongoose, express-related packages, deprecated `request`). Not needed to run; not done.
- Optional: add `.nvmrc` / raise `engines` for Node 24.
